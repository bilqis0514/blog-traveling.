# 🌍 Proyek Blog Traveling - Sistem Informasi Manajemen

Proyek ini dibuat untuk memenuhi tugas **Soal 4.10: Achieving Operational Excellence: Creating a Simple Blog** menggunakan platform **GitHub Pages**.

## 📌 Informasi Proyek
- **Tema Blog:** Traveling & Pariwisata (*Jejak Langkah*)
- **Jumlah Postingan:** 4 Entri lengkap dengan label/tag kategori.
- **Fitur:** Desain responsif HTML/CSS, penambahan gambar ilustrasi, dan struktur blog sederhana.

---

## 💼 Analisis Bisnis (Business Use Case)

### 1. Kegunaan Blog bagi Perusahaan Terkait (Tour & Travel / Industri Pariwisata)
- **Media Content Marketing:** Perusahaan dapat mempublikasikan artikel destinasi wisata, panduan perjalanan, dan ulasan pengalaman untuk menarik minat calon pelanggan secara organik.
- **Membangun Hubungan dengan Pelanggan:** Menyediakan informasi yang akurat dan interaktif dapat meningkatkan kepercayaan (*trust*) konsumen terhadap layanan agen perjalanan.
- **Meningkatkan Visibilitas (SEO):** Membantu perusahaan tampil lebih mudah di mesin pencari ketika pengguna mencari informasi seputar liburan.

### 2. Tools yang Tersedia di GitHub dan Kegunaannya untuk Bisnis
- **GitHub Pages:** Berfungsi untuk melakukan *hosting* situs web statis atau blog secara gratis tanpa memerlukan biaya server atau domain berbayar tambahan.
- **Git / Version Control:** Memungkinkan tim pengembang atau pemasaran untuk melacak riwayat perubahan, revisi konten, serta memperbarui artikel secara aman dan terstruktur.
- **GitHub Issues:** Dapat dimanfaatkan sebagai media interaksi untuk menampung masukan, laporan kendala (*bug*), atau ruang diskusi kolaborasi antar anggota tim (*team members*).
